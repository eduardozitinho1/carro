# carro

Literalmente, UM CARRO

## Como instalar

É muito fácil, só instalar com:

```bash
pip install carro
```

## Manual

Você vem no jogo com um carro. Esse carro inicialmente só tem máximo de 150km/h, e seu objetivo é ficar milionário COM UM CARRO.

### Eventos aleatórios

- Acidente: Renicie o jogo, você morreu.
- Imprudência: Você bebeu álcool antes de viajar! Chance de ir preso e esperar 90 segundos com chance mínima de se dar mal na cadeia e morrer.
- Trânsito: Você tem que esperar um tempo entre 2 a 8 segundos antes de voltar à viagem.

### Upgrades

- Airbags: Chance menor de acidente a cada airbag comprado.
- Advogados: Chance menor de ir preso
- Velocidade: Tá querendo chegar mais rápido em seus locais preferidos? Aumente sua velocidade em 25km/h por um custo!

### Trabalho

Você consegue trabalhar com entregas atualmente. Vá até o estado necessário e conclua a entrega proposta para receber tua merreca– não, seu dinheiro precioso!
