# Eventos

As viagens possuem eventos aleatórios.

Isso significa que duas viagens semelhantes não necessariamente terão o mesmo resultado.

Atualmente existem três eventos principais:

- trânsito;
- imprudência;
- acidente.

## Trânsito

O trânsito interrompe temporariamente a viagem.

Quando ocorre um congestionamento, você precisa esperar entre:

**2 e 8 segundos**

Depois desse período, a viagem continua.

O trânsito não cancela a viagem.

## Imprudência

A imprudência representa uma situação em que o jogador dirige após consumir álcool.

Quando ocorre:

1. a polícia pode perceber a condução suspeita;
2. pode ocorrer uma abordagem;
3. existe uma chance de realização do bafômetro;
4. se o álcool for detectado, existe risco de prisão.

Se a viagem for interrompida por esse evento, ela precisa ser refeita.

Advogados reduzem o risco de prisão.

## Acidente

Acidentes podem acontecer durante uma viagem.

Se um acidente ocorrer:

- a viagem é interrompida;
- o trajeto precisa ser refeito;
- o combustível utilizado na tentativa é restaurado;
- airbags podem reduzir a chance de o acidente acontecer.

O jogador não fica imune a acidentes mesmo com airbags.

## Aleatoriedade

Os eventos são probabilísticos.

Portanto:

> Uma viagem segura anteriormente não garante que a próxima viagem será segura.

O objetivo dos upgrades é alterar as probabilidades do jogo, e não eliminar completamente os riscos.

## Risco e recompensa

O jogador precisa administrar o risco.

Viajar é necessário para completar trabalhos, mas viajar também expõe o jogador aos eventos aleatórios.

Conforme o patrimônio aumenta, investir em upgrades pode reduzir alguns desses riscos.
