# Primeiros passos

O `carro` começa de forma simples: você possui um carro, R$50,00 e a vontade de ficar rico.

## Instalação

O pacote está disponível no PyPI.

```bash
pip install carro
```

Depois da instalação, execute:

```bash
carro
```

## Seu primeiro carro

Ao começar o jogo, você possui:

- R$50,00;
- um carro;
- velocidade máxima inicial de 150 km/h;
- combustível;
- nenhum upgrade;
- nenhuma entrega concluída.

Você começa em **São Paulo**.

## Primeiro trabalho

O caminho mais simples para começar a ganhar dinheiro é trabalhar com entregas.

No menu principal, escolha a opção de trabalho.

O jogo apresentará o trabalho disponível para o estado onde você está.

Depois de aceitar uma entrega, você precisa viajar até o destino dela.

Quando chegar ao destino correto, a entrega será concluída e você receberá o pagamento.

## Primeira viagem

Para viajar, seu carro precisa estar em movimento.

Primeiro, acelere:

```text
2. Acelerar
```

Depois escolha:

```text
5. Viajar
```

O jogo mostrará os destinos disponíveis.

Escolha o destino desejado e aguarde a viagem.

Durante o trajeto, eventos aleatórios podem acontecer.

## Como ganhar dinheiro

O ciclo básico do jogo é:

```text
Trabalho
   ↓
Viagem
   ↓
Entrega
   ↓
Pagamento
   ↓
Upgrade
   ↓
Trabalhos melhores
   ↓
Mais dinheiro
```

O objetivo é transformar o pequeno capital inicial em uma grande fortuna.
