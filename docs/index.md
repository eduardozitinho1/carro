# carro

Literalmente, UM CARRO.

Você começa com um carro e R$50,00.

Seu objetivo é simples:

> Trabalhe. Viaje. Ganhe dinheiro. Compre upgrades. Fique milionário.

O `carro` é um jogo de gerenciamento em que você começa praticamente sem nada e precisa construir sua fortuna usando apenas o seu carro.

## Começando

Para instalar:

```bash
pip install carro
```

Depois, execute:

```bash
carro
```

Se você nunca jogou antes, comece pelo [guia de primeiros passos](getting-started.md).

## O que você pode fazer?

### Trabalhar

Faça entregas entre diferentes estados para ganhar dinheiro.

Cada região possui oportunidades diferentes, e algumas exigem que você tenha experiência suficiente para conseguir o trabalho.

Veja como funciona em [Trabalhos](jobs.md).

### Viajar

Seu carro é o seu principal recurso.

Viaje pelo Brasil para chegar aos locais das entregas, mas tome cuidado: durante as viagens, diversos eventos podem acontecer.

### Comprar upgrades

Use o dinheiro que ganhou para melhorar seu carro e aumentar suas chances de progresso.

Você pode comprar:

- Airbags — reduzem a chance de acidentes.
- Advogados — reduzem o risco de prisão.
- Velocidade — aumentam a velocidade máxima do carro em 25 km/h por upgrade.

Veja todos os upgrades em [Upgrades](upgrades.md).

### Enfrentar eventos

As viagens não são completamente previsíveis.

Você pode encontrar:

- acidentes;
- imprudência;
- trânsito.

Alguns eventos são apenas inconvenientes. Outros podem acabar com a sua viagem — ou até com o seu jogo.

Veja [Eventos](events.md).

## Prisão

Se você for preso, terá que cumprir uma sentença de 90 segundos.

Durante esse período, existe uma pequena chance de algo dar muito errado.

Mais detalhes em [Prisão](prison.md).

## Progressão

No começo, R$50,00 parece pouco.

Com trabalho, viagens e upgrades, você pode aumentar seus ganhos, assumir trabalhos melhores e construir seu patrimônio.

O objetivo final?

**Virar uma magnata.**

Consulte [Progressão](progression.md) para entender como o jogo evolui.
