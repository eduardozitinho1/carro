# Upgrades

O dinheiro ganho com trabalhos pode ser utilizado para melhorar o carro.

Atualmente existem três categorias principais de upgrades:

- velocidade;
- airbags;
- advogados.

## Velocidade

O upgrade de velocidade aumenta a velocidade máxima do carro.

A velocidade máxima inicial é:

**150 km/h**

Cada upgrade adiciona:

**+25 km/h**

Por exemplo:

```text
Nível 0 → 150 km/h
Nível 1 → 175 km/h
Nível 2 → 200 km/h
Nível 3 → 225 km/h
```

Quanto maior a velocidade, menor o tempo necessário para percorrer uma determinada distância.

O custo aumenta conforme você compra novos upgrades.

## Airbags

Airbags reduzem a chance de um acidente durante uma viagem.

Cada nível de airbags fornece uma redução adicional no risco.

Eles não tornam o carro completamente imune a acidentes.

O objetivo é reduzir o risco, não eliminá-lo.

## Advogados

Advogados reduzem a chance de você ser preso quando ocorre uma situação de imprudência envolvendo a polícia.

Quanto mais advogados você possui, menor é o risco de prisão.

Eles são especialmente importantes para jogadores que fazem viagens arriscadas.

## Custo dos upgrades

Os upgrades possuem custos que aumentam conforme novos níveis são adquiridos.

Portanto, não basta acumular um único upgrade indefinidamente sem considerar o seu patrimônio.

Você precisa decidir onde investir seu dinheiro.

## Qual upgrade comprar?

Não existe uma única forma de jogar.

Você pode priorizar:

### Velocidade

Útil para reduzir o tempo das viagens.

### Airbags

Úteis para reduzir o risco de acidentes.

### Advogados

Úteis para reduzir o risco de prisão.

O sistema permite diferentes estratégias de progressão.
